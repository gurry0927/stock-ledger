# 股票帳本

純 HTML、CSS、JavaScript 的台股離線記帳網頁，沒有後端，也不會上傳交易資料。記錄、設定與未送出的表單草稿都存在瀏覽器 IndexedDB。

內建上市、上櫃股票（含 KY）與 ETF 離線清單，可用代號或名稱互相帶入。清單含商品分類，讓賣出稅率能區分股票、一般 ETF 與債券 ETF。

## 使用方式

- 電腦：直接開啟 `index.html`。
- iPhone 主畫面：需先把整個資料夾放在 HTTPS 靜態網址，以 Safari 開啟後選「分享 → 加入主畫面」。安裝並載入一次後可離線使用。
- 資料備份：在「設定與備份」匯出 CSV；改版、清除 Safari 網站資料或換手機前務必備份。

`file://` 可直接使用 IndexedDB，但不能註冊 Service Worker；這不影響電腦單機使用。iPhone 主畫面與完整離線快取則需要 HTTPS。

## 計算規則

### 手續費

買進與賣出都會估算手續費：

```text
成交金額 × 0.1425% ×（折數 ÷ 10）
```

再依股數套用整股或零股的「每筆最低手續費」。折數、兩種最低費用以及元以下處理方式都能在設定修改。這些條件依券商而異，對帳單金額可在單筆記錄中覆寫。

### 證券交易稅

- 買進：不收證交稅。
- 股票／KY 股賣出：一般 0.3%。
- 符合規定的現股當沖：適用期間 0.15%。
- 一般 ETF 賣出：0.1%。
- 非槓桿、非反向債券 ETF：程式依目前法規期限，在 2026-12-31 前估為 0%；期限後回到 ETF 稅率。

所有估算都應以券商對帳單為準。每筆新記錄會保存當時的費率、最低費用、稅則、估算與實際覆寫值；日後修改設定不會改動既有記錄。舊版記錄沒有這些快照，畫面會清楚標示為依目前設定估算。

查核來源（2026-08-08）：[證交所營業細則第 94 條](https://twse-regulation.twse.com.tw/TW/law/DOC01.aspx?FLCODE=FL007304&FLNO=94)、[證交所交易成本說明](https://www.twse.com.tw/zh/about/company/guide.html)、[財政部證券交易稅條例](https://law-out.mof.gov.tw/LawContent.aspx?id=FL006079&media=print)。法規與優惠期限仍可能修改，程式中的期限到了之後應再次查核。

## 持股、投資輪次與回本成本

持股摘要完全由原始流水按日期推導，不會把計算結果回寫或覆蓋交易資料。

- 帳面成本：買進實際支出納入成本；部分賣出時，以移動平均成本扣除售出股數的成本。
- 賣出已實現損益：賣出淨收入減去售出股數的移動平均成本。
- 回本成本：本輪所有買進實際支出，扣除賣出淨收入、實收配息與現金減資收入。
- 配股與分割：只調整股數，總成本不變。
- 虧損減資：只減少股數；現金減資另扣除實收現金。
- 持股歸零：結束目前投資輪次；下次買進同一代號會從新一輪成本開始。

配息日期建議填「除息日」，以便在清倉或重新買進前歸入正確輪次。回本成本是個人投資追蹤指標，不代表券商帳面或稅務機關認定成本。

記錄頁提供兩層檢視，但不會建立第二份資料：

- 「個股總覽」依股票代號集中顯示持有中與已清倉股票；點選個股後可切換「投資輪次」與「個股流水帳」。
- 「全部流水帳」保留所有交易依日期排列的檢視與類型篩選。
- 全部總覽、輪次與個股流水都是從同一份 IndexedDB 原始記錄即時計算；清倉後再次買進會顯示為下一輪。

## 昨日收盤行情（獨立參考）

持股卡片可顯示參考收盤價、參考市值與未實現損益。未實現損益以「參考市值－剩餘帳面成本」計算；行情不會寫進交易記錄，也不參與手續費、稅額、帳面成本、回本成本或投資輪次計算。行情載入或更新失敗時，所有記帳功能仍可正常使用。

- 直接用 `file://` 開啟：讀取隨程式附上的 `prices.js` 快照，不會對外連線。
- 部署在 HTTPS：先立即使用內建或 IndexedDB 快取，再於背景讀取同網址的 `prices.json`；每日最多自動檢查一次，也可手動重試。
- 行情檔包含程式支援的上市、上櫃股票、KY 股與 ETF，不會只抓目前持股。
- 不需要 API key。產生行情檔時才讀取證交所及櫃買中心的公開資料；使用帳本時不會把交易資料傳給行情來源。

更新隨附行情（需要 Node.js 與網路）：

```sh
node tools/update-prices.mjs
```

這會一起覆寫 `prices.json`（HTTPS 背景更新來源）與 `prices.js`（`file://` 內建快照）。純靜態網站本身無法定時改寫檔案；若未來要每天自動產生新版，可在靜態網站的部署流程排程執行這支工具，不需要替帳本建立後端。

## 資料安全設計

- 表單輸入後會短暫延遲並自動保存草稿；重新開啟可復原。
- 只有 IndexedDB 交易完整成功後才清空表單。
- 編輯既有記錄時會先在同一交易確認原記錄仍存在；若已被另一分頁刪除，舊分頁不能把它重新寫回。
- CSV 先完整解析與驗證，再以單一 IndexedDB 交易寫入；其中一列失敗，整批都不寫入。
- CSV v4 包含費用、稅額與事件欄位快照，並防止文字被試算表當成公式；仍可匯入舊版 CSV。
- 數字會檢查有限值、正整數股數與 JavaScript 安全整數金額範圍。
- 異常的既有記錄不會被自動刪除，會保留並提示先匯出備份。

瀏覽器資料仍可能因使用者清除網站資料、裝置損壞或系統儲存政策而消失，因此 CSV 是跨裝置與長期保存的主要備份。

## 示範資料

- 全新的空白帳本第一次開啟會建立 17 筆、5 個虛構代號的示範記錄；已有正式記錄的帳本不會自動加入。
- 示範涵蓋買賣、部分賣出、虧損清倉、清倉後第二輪、配息、配股、分割與現金減資，畫面上都有「示範」標記。
- 可在「設定與備份 → 操作示範資料」載入、重設或整批刪除。刪除記錄與「不要再次自動建立」狀態會在同一個 IndexedDB 交易完成，失敗時一起回滾。
- CSV 匯出不包含示範記錄，匯入時也會略過保留的示範 ID，避免它們隨備份回來。
- 正常重新開啟、程式升級或繼續使用舊分頁都不會讓已刪除的示範資料重生。只有主動按「載入／重設示範」，或把這個網站的全部 IndexedDB／Safari 網站資料清除成全新安裝，才會再次出現。

## 程式結構

```text
index.html                 畫面結構
styles.css                 手機優先樣式
stocks.js                  離線商品清單
prices.js                  file:// 使用的內建收盤行情快照
prices.json                HTTPS 每日檢查的靜態行情檔
scripts/config.js          常數、費率與共用工具
scripts/calculator.js      手續費、稅額與快照計算
scripts/demo-data.js       可辨識、可整批移除的操作示範資料
scripts/portfolio.js       持股、移動平均成本與投資輪次推導
scripts/ledger-model.js    個股索引、流水分組與搜尋篩選
scripts/storage.js         IndexedDB 與原子交易
scripts/market-data.js     獨立行情驗證、快取與每日檢查
scripts/csv.js             CSV v4 匯出、驗證與舊版相容
scripts/records-view.js    個股卡、輪次卡與流水項目畫面
scripts/app.js             畫面事件與流程協調
sw.js                      HTTPS/PWA 離線快取
tools/update-prices.mjs    從官方公開資料產生精簡行情檔
tests/                     不需安裝套件的 Node 測試
```

執行測試：

```sh
node --test tests/*.test.js
```
